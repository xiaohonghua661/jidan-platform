# 记单平台

给接单做毕设、课设的小工作室用的**本地记单系统**。订单按类别存成 JSON；AI（Claude、Codex 等）只能通过一个命令行入口写入；人用本地网页看板查看、筛选、手动打钩；每天定时弹窗提醒还有哪些单要做。

只用 Python 标准库和一个 HTML 文件，不用装依赖（导入旧 Excel 台账时才要 `openpyxl`）。在 Windows 上开发和使用；看板和命令行在其它系统上也能跑，每日提醒只支持 Windows。

## 能做什么

- **看板**（`app.py` + `index.html`，本机 `http://127.0.0.1:8765/`）
  - 类别页签、5 个指标卡（订单、总价、已结账、未结账、没做完的急单）
  - 老板面板：每个老板的单数、未结账、总价，点一下只看他的单，可按未结 / 单数 / 金额 / 名称排序
  - 状态自动算：未开始 / 进行中 / 待结款 / 已结款；按渠道、月份、结款周筛选，搜索，任意列排序
  - 每单一排环节进度（完成 / 有记录 / 待定 / 待结 / 未做 / 不做），期限快到或逾期会标出来
  - 点行看详情；深色模式跟随系统；「复制当前列表」可直接粘进 Excel 或聊天窗口
- **看板上手动修改**：环节打 √ / X / 空（要再按「确定」），环节里写日期、快递号，改备注、期限、价格。每处改动记进 `手动改动.jsonl`，AI 下次和你对话时逐条问是不是你本人改的（`ledger.py manual / confirm / reject`）。
- **写入口 `ledger.py`**：`add / set / list / export / check / import`，带文件锁和原子写入；`export` 按渠道的台账列序出一行，方便手填 Excel。
- **每日提醒 `remind.py`**：用 Windows 计划任务按时提醒。当天第一次弹大窗，之后有待办就在右下角弹小窗；备注里写着「开题」的未开始单单独列出，不算待办；看板右上角「提醒」或 `立即提醒.bat` 随时弹。
- **配置驱动**：类别和各自的环节、渠道的计价方式和台账列序、提醒时间，都在 `配置/*.json`，加类别、加渠道不改代码。

## 目录约定

平台目录放在工作区里，和各类别的员工目录平级；订单数据不在平台目录里：

```
<工作区>\
├── 04_记单平台\          ← 本仓库（目录名随意，下文都按 04_记单平台 写）
├── shiwu\订单库\         ← 实物单，每月一个 YYYYMM.json
├── fangzhen\订单库\      ← 仿真单
└── ...
```

- 类别和目录的对应关系在 `配置/类别.json`。**第一次记单前先按自己的分类改好它**：程序每次运行都会给配置里的每个类别补建 `订单库` 目录（已有的不动）。
- 自带的分类是作者自己的（实物 / 仿真 / 8086 / 论文），渠道是「中介」（一口价）和「直客」（定金 + 尾款），都只是示例。

## 安装

1. 装 Python 3.10 以上，命令行里 `python` 能运行（python.org 或 Anaconda 都行）。
2. 把本仓库放进工作区，二选一：
   - 装了 Git：在工作区目录里执行 `git clone -b main <本仓库地址> 04_记单平台`（地址在仓库页面右上角绿色 Code 按钮里）。以后升级在 `04_记单平台` 里 `git pull`。
   - 没装 Git：仓库页面点 Code → Download ZIP，解压到工作区，把解压出的文件夹改名为 `04_记单平台`。
3. 按上一节改好 `04_记单平台\配置\类别.json`（和 `渠道.json`）。

## 用法

下面的命令都在**工作区目录**里执行（命令行先 `cd` 到工作区）。路径写的是 Windows 的反斜杠；在 Git Bash 等 shell 里换成 `/`。

```
python 04_记单平台\ledger.py add shiwu A-26-001 题目=测试单 价格=300 日期=20261015 老板=王工 --写入者 我
python 04_记单平台\ledger.py set shiwu A-26-001 原理图=√ PCB=X 打板=20261018
python 04_记单平台\ledger.py list
python 04_记单平台\ledger.py export shiwu A-26-001 --表头
python 04_记单平台\ledger.py check
```

- 环节值：`√` 或「完成」= 完成，`X` 或「不做」= 不做，空或「未做」= 未做；别的文字原样存（日期、快递号、待定）。
- 渠道：不写时默认「中介」（一口价，用 `价格=`）；定金尾款的单写 `渠道=直客 定金=400 尾款=500`。把「中介」改名或删掉后，每条 add 都要带 `渠道=`。
- `--写入者` 记的是**最后一次**写这单的人（每次 add / set 都会覆盖），不写时记成 `ai`；看板详情最下面一行能看到。
- `list` 第一行是列名，后面每单一行，用 Tab 分隔。
- `export` 出的是一行台账文本：单号那一格是「单号 + 题目」连写；`配置/渠道.json` 里 `台账列` 的「环节」会展开成这一类别的每个环节。
- 导入旧 Excel 台账（要先 `pip install openpyxl`）：`python 04_记单平台\ledger.py import 旧台账.xlsx --类别 shiwu --渠道 中介 --月 202608`。表格第一行是表头，认这些列：时间、工程师、单号、价格、定金、尾款、各环节名、结款工程师（记成老板）、备注；单号格子里的「单号 + 题目」会自动拆开，已有的单号跳过。

### 看板

- 双击 `04_记单平台\启动记单平台.bat`（或 `python 04_记单平台\app.py`），浏览器自动打开 `http://127.0.0.1:8765/`。
- 8765 被占用时自动往后换（8766…8774）；已经开着一个就直接打开它。也可以 `python 04_记单平台\app.py --port 9000` 指定端口，`--no-browser` 不开浏览器。
- 那个黑窗口就是看板服务，关掉它看板就停了。

### 每日提醒（Windows）

- 双击 `安装每日提醒.bat`：用当前用户注册一个叫「记单平台每日提醒」的计划任务，不要管理员权限。时间在 `配置/提醒.json`（默认 9:00、14:00、20:00，另加开机登录后 1 分钟），改完再双击一次才生效。
- `立即提醒.bat` 随时弹，`卸载每日提醒.bat` 删除，`python 04_记单平台\remind.py --status` 查看下次提醒时间，`--text` 只在命令行打印今天的待办。
- 计划任务里记的是脚本的绝对路径：挪动了工作区或平台目录，要重新双击 `安装每日提醒.bat`。`--status` 只按任务名查，不核对路径。

## 升级与备份

- 订单数据在各类别的 `订单库\` 里，备份这些目录就行。
- 平台目录里有几样运行时产生、不进仓库的文件：`手动改动.jsonl`（看板手动改动的记录，没确认的改动也在里面）、`.提醒状态.json`。重装或删平台目录前把 `手动改动.jsonl` 拷出来。
- 用 Git 装的：在 `04_记单平台` 里 `git pull`。改过 `配置/*.json` 的，先 `git stash`，再 `git pull`，最后 `git stash pop` 把你的配置放回来（漏了最后一步，配置会变回示例的 4 个类别）。
- 用 ZIP 装的：重新下载解压前，先把 `配置\` 和 `手动改动.jsonl` 拷出来，解压后再拷回去。

## 给 AI 的规矩

见 [`AI必读.md`](AI必读.md)。要点：

- AI 只能通过 `ledger.py` 写，不手改 JSON、不写 Excel 台账；调用时用 `python -I <平台目录>\ledger.py …`（`-I` 不加载当前目录里的同名模块，更稳）。
- 读写记单前先跑 `ledger.py manual`：看板上有用户手动改过的地方，就在对话里逐条确认，用户说是就 `confirm`，不是就 `reject` 改回。

`AI必读.md` 里「接新单：开单号会话」「上云项目」两节是作者自己的工作流（Claude 桌面版、ESP-01S + OneNET 项目），按自己的情况删改。文档里的 `<平台目录>`、`<工作区>`、王工、A-26-001 等都是示例。
