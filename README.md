# 记单平台

给接单做毕设、课设的小工作室用的**本地记单系统**。订单按类别存成 JSON；AI（Claude、Codex 等）只能通过一个命令行入口写入；人用本地网页看板查看、筛选、手动打钩；每天定时弹窗提醒还有哪些单要做、该找谁结款、今天哪个店铺还没推广。

只用 Python 标准库和一个 HTML 文件，不用装依赖（导入旧 Excel 台账时才要 `openpyxl`）。在 Windows 上开发和使用；看板和命令行在其它系统上也能跑，每日提醒只支持 Windows。

## 能做什么

- **看板**（`app.py` + `index.html`，本机 `http://127.0.0.1:8765/`）
  - 类别页签、6 个指标卡（订单、总价、已结账、未结账、没做完的急单、本月私单成本）；「未结账」卡下面写着其中待结款几单、可以催了（自己接的单不算）
  - 老板面板：每个老板的单数、未结账、总价，点一下只看他的单，可按未结 / 单数 / 金额 / 名称排序
  - 状态自动算：未开始 / 进行中 / 待结款 / 已结款；按渠道、月份、结款周筛选，搜索，任意列排序
  - 每单一排环节进度（完成 / 有记录 / 待定 / 待结 / 未做 / 不做），期限快到或逾期会标出来；可以按环节藏起已经做完的单，行尾「隐藏」单独藏起某一单
  - 点行看详情；深色模式跟随系统；「复制当前列表」可直接粘进 Excel 或聊天窗口
  - 侧栏「私单成本」：按月看各店铺的推广费、回本没有，记一笔、作废一笔
  - 「导出结款」：按结款工程师出结款单、按单个老板出对账单，复制就能发；钱到账了可以一键结款
- **看板上手动修改**：环节打 √ / X / 空（要再按「确定」），环节里写日期、快递号，改备注、期限、价格、来源；记一笔 / 作废一笔私单成本；一键结款。每处改动记进 `手动改动.jsonl`，AI 下次和你对话时逐条问是不是你本人改的（`ledger.py manual / confirm / reject`）。
- **写入口 `ledger.py`**：`add / set / list / export / check / import / manual / confirm / reject / settle / cost`，带文件锁和原子写入；`export` 按渠道的台账列序出一行，方便手填 Excel。价格必填（不带价格的 `add` 会被拒）；同一单号在两个类别都记了钱会提醒。
- **导出结款 `ledger.py settle`**：先跟各个老板对账，再统一找结款工程师结款；谁归谁结款写在 `配置/结款.json`。结款从没打钩变成打钩时，往 `结款记录.jsonl` 记一笔时间。
- **私单成本 `ledger.py cost`**：各店铺的推广费按月记，算推广来的单回本没有。
- **每日提醒 `remind.py`**：用 Windows 计划任务按时提醒。当天第一次弹大窗，之后有待办就在右下角弹小窗；备注里写着「开题」的未开始单单独列出，不算待办；没填价格的单、今天还没推广的店铺排在前面；「待结款，可以催了」按老板列，不含自己接的单，每个老板后面写上次结款是多少天前。看板右上角「提醒」或 `立即提醒.bat` 随时弹。
- **配置驱动**：类别和各自的环节、渠道的计价方式和台账列序、提醒时间、店铺和推广方式、结款名单，都在 `配置/*.json`，加类别、加渠道、加店铺不改代码。

## 目录约定

平台目录放在工作区里，和各类别的员工目录平级；订单数据不在平台目录里：

```
<工作区>\
├── 04_记单平台\          ← 本仓库（目录名随意，下文都按 04_记单平台 写）
├── shiwu\订单库\         ← 实物单，每月一个 YYYYMM.json
├── fangzhen\订单库\      ← 仿真单
└── ...
```

- 类别和目录的对应关系在 `配置/类别.json`。**第一次记单前先按自己的分类改好它**：程序每次运行都会给配置里的每个类别补建 `订单库` 目录（已有的不动）。
- 自带的配置都只是示例：分类是作者自己的（实物 / 仿真 / 8086 / 论文 / 软件 / 网络）；渠道是「中介」（一口价）、「直客」（定金 + 尾款）、「自营」（自己接的单，一口价）；店铺是「闲鱼店」「淘宝店」（`配置/成本.json`）；结款名单里的陈工、郑工等也是示例（`配置/结款.json`）。
- 私单成本存在平台目录的 `成本库\`，另有几份运行记录也在平台目录里，见「升级与备份」。

## 安装

1. 装 Python 3.10 以上，命令行里 `python` 能运行（python.org 或 Anaconda 都行）。
2. 把本仓库放进工作区，二选一：
   - 装了 Git：在工作区目录里执行 `git clone -b main <本仓库地址> 04_记单平台`（地址在仓库页面右上角绿色 Code 按钮里）。以后升级在 `04_记单平台` 里 `git pull`。
   - 没装 Git：仓库页面点 Code → Download ZIP，解压到工作区，把解压出的文件夹改名为 `04_记单平台`。
3. 按上一节改好 `04_记单平台\配置\类别.json`（和 `渠道.json`；记推广费、导出结款的，再改 `成本.json`、`结款.json`）。

## 用法

下面的命令都在**工作区目录**里执行（命令行先 `cd` 到工作区）。路径写的是 Windows 的反斜杠；在 Git Bash 等 shell 里换成 `/`。

```
python 04_记单平台\ledger.py add shiwu A-26-001 题目=测试单 价格=300 日期=20261015 老板=郑工 --写入者 我
python 04_记单平台\ledger.py set shiwu A-26-001 原理图=√ PCB=X 打板=20261018
python 04_记单平台\ledger.py list
python 04_记单平台\ledger.py export shiwu A-26-001 --表头
python 04_记单平台\ledger.py check
```

- 环节值：`√` 或「完成」= 完成，`X` 或「不做」= 不做，空或「未做」= 未做；别的文字原样存（日期、快递号、待定）。
- 价格必填：一口价写 `价格=`，定金尾款的写 `定金=` `尾款=`，自己的项目可以写 `价格=0`；`set` 不能把价格清空。
- 渠道：不写时默认「中介」（一口价，用 `价格=`）；写了 `老板=自己` 的默认「自营」；定金尾款的单写 `渠道=直客 定金=400 尾款=500`。把「中介」「自营」改名或删掉后，对应的 add 都要带 `渠道=`。
- `来源=` 写这单是从哪个店铺来的（要是 `配置/成本.json` 的「店铺」里有的），用来算推广回本；不是推广来的不写。
- `--写入者` 记的是**最后一次**写这单的人（每次 add / set 都会覆盖），不写时记成 `ai`；看板详情最下面一行能看到。
- `list` 第一行是列名，后面每单一行，用 Tab 分隔。
- `export` 出的是一行台账文本：单号那一格是「单号 + 题目」连写（填了 `全称=` 就用全称）；`配置/渠道.json` 里 `台账列` 的「环节」会展开成这一类别的每个环节。
- `check` 查出问题时退出码为 1；没归到结款工程师的老板、可能重复记钱的单号、等你确认的看板手动改动也会提一句。
- 导入旧 Excel 台账（要先 `pip install openpyxl`）：`python 04_记单平台\ledger.py import 旧台账.xlsx --类别 shiwu --渠道 中介 --月 202608`。表格第一行是表头，认这些列：时间、工程师、单号、价格、定金、尾款、各环节名、结款工程师（记成老板）、备注；单号格子里的「单号 + 题目」会自动拆开，已有的单号跳过。

### 导出结款

```
python 04_记单平台\ledger.py settle 郑工                   # 对账单：郑工的待结款单
python 04_记单平台\ledger.py settle 陈工                   # 结款单：陈工自己的单 + 归他结款的每个人各一段，最后合计
python 04_记单平台\ledger.py settle                        # 每个结款工程师一份，没归属的老板单列
python 04_记单平台\ledger.py settle 陈工 --周 1018-1024 --含未完成
python 04_记单平台\ledger.py settle 陈工 --结清            # 钱到账了：上面列出的单全部标成已结款
```

- 谁归谁结款写在 `配置/结款.json`：`{"结款工程师": {"陈工": ["郑工", "孙工"]}}`，名字要和订单的「老板」一字不差。
- 默认只列待结款（活干完了、钱没结）的单，金额是还欠的钱（定金按已收算）；`--含未完成` 连没干完的也列，`--周` 只看某个结款周。
- `--结清` 一次只结一个人。看板表格底部「导出结款」做同样的事，每张卡片有「一键结款」，点了要再按「确定，钱到账了」。

### 私单成本（推广费）

```
python 04_记单平台\ledger.py cost add 店铺=闲鱼店 方式=擦亮 金额=30
python 04_记单平台\ledger.py cost add 店铺=淘宝店 方式=投放 金额=100 天数=7 日期=20261021
python 04_记单平台\ledger.py cost list --月 202610         # 明细、按平台和按月汇总、回本
python 04_记单平台\ledger.py cost set C202610-0001 方式=推广
python 04_记单平台\ledger.py cost del C202610-0001         # 作废：留底，不再算钱
```

- 店铺先在 `配置/成本.json` 的「店铺」里加：属于哪个平台、要不要每天提醒推广（`每天推广`）。
- `天数` 不写就是「用完为止」（充进去花完就停）；一次投好几天的写天数，到期前后提醒续不续。钱哪天花的就算哪个月。
- 回本 = 订单里 `来源` 写了这个店铺的单的成交额，减去推广费。

### 看板

- 双击 `04_记单平台\启动记单平台.bat`（或 `python 04_记单平台\app.py`），浏览器自动打开 `http://127.0.0.1:8765/`。
- 8765 被占用时自动往后换（8766…8774）；已经开着一个就直接打开它。也可以 `python 04_记单平台\app.py --port 9000` 指定端口，`--no-browser` 不开浏览器。
- 那个黑窗口就是看板服务，关掉它看板就停了。

### 每日提醒（Windows）

- 双击 `安装每日提醒.bat`：用当前用户注册一个叫「记单平台每日提醒」的计划任务，不要管理员权限。时间在 `配置/提醒.json`（默认 9:00、14:00、20:00，另加开机登录后 1 分钟），改完再双击一次才生效。
- `立即提醒.bat` 随时弹，`卸载每日提醒.bat` 删除，`python 04_记单平台\remind.py --status` 查看下次提醒时间，`--text` 只在命令行打印今天的待办，`--dry` 只说这次会弹哪种窗、不弹。
- 计划任务里记的是脚本的绝对路径：挪动了工作区或平台目录，要重新双击 `安装每日提醒.bat`。`--status` 只按任务名查，不核对路径。

## 升级与备份

- 订单数据在各类别的 `订单库\` 里，私单成本在平台目录的 `成本库\` 里，备份这些目录就行。
- 平台目录里还有几样运行时产生、不进仓库的文件：`手动改动.jsonl`（看板手动改动的记录，没确认的改动也在里面）、`结款记录.jsonl`（每单结款打钩的时间，提醒里算上次结款多久了）、`.提醒状态.json`。重装或删平台目录前把 `成本库\` 和这两个 `.jsonl` 拷出来。
- 用 Git 装的：在 `04_记单平台` 里 `git pull`。改过 `配置/*.json` 的，先 `git stash`，再 `git pull`，最后 `git stash pop` 把你的配置放回来（漏了最后一步，配置会变回示例的 6 个类别）。
- 用 ZIP 装的：重新下载解压前，先把 `配置\`、`成本库\`、`手动改动.jsonl`、`结款记录.jsonl` 拷出来，解压后再拷回去。

## 给 AI 的规矩

见 [`AI必读.md`](AI必读.md)。要点：

- AI 只能通过 `ledger.py` 写，不手改 JSON、不写 Excel 台账；调用时用 `python -I <平台目录>\ledger.py …`（`-I` 不加载当前目录里的同名模块，更稳）；`remind.py`、`app.py` 不加 `-I`，它们要导入同目录的 `ledger.py`。
- 读写记单前先跑 `ledger.py manual`：看板上有用户手动改过的地方，就在对话里逐条确认，用户说是就 `confirm`，不是就 `reject` 改回。
- 价格必填：用户没说多少钱就先问，不留空。

文档里的 `<平台目录>`、`<工作区>`、陈工、郑工、闲鱼店、A-26-001 等都是示例。
